Update monthly data

Upload one Excel file (.xlsx) — the Enquiry workbook. It must contain these 3 sheets:

  • Enquiry — all enquiries (Booking and Retail are read from the Enquiry Status column)
  • Physical Stock — vehicles physically in stock
  • In Transit — vehicles despatched but not yet received

Keep the sheet names and column headings the same every month. Everything recalculates immediately and Month Comparison updates automatically. If the file is wrong, your current data is kept.
